Questo è un elemento di portfolio di esempio. Quando aggiungi nuovi elementi di portfolio tramite il pannello di amministrazione di Decap CMS (a https://naveldesign.com/admin), verranno visualizzati automaticamente qui.

## Come aggiungere elementi di portfolio

1. Vai a **https://naveldesign.com/admin**
2. Accedi con il tuo account GitHub
3. Fai clic su **Elementi Portfolio** nel menu a sinistra
4. Fai clic su **Nuovo elemento di portfolio**
5. Compila i dettagli:
   - **Titolo**: Il nome della tua opera
   - **Descrizione**: Una breve descrizione (visualizzata nella griglia)
   - **Immagine**: Carica una foto del tuo lavoro
   - **In Evidenza**: Seleziona questa casella per evidenziarla
   - **Categoria**: Scegli Arredamento, Accessori o Personalizzato
   - **Dettagli**: Scrivi una descrizione più lunga

6. Fai clic su **Pubblica** - l'elemento appare automaticamente sul tuo sito web!

Tutte le immagini vengono archiviate nel tuo repository e servite direttamente. ogni versione in lingua può avere testi diversi mentre condivide le stesse immagini.
