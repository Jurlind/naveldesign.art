This is a sample portfolio item. When you add new portfolio items through the Decap CMS admin panel (at https://naveldesign.com/admin), they will appear here automatically.

## How to Add Portfolio Items

1. Go to **https://naveldesign.com/admin**
2. Log in with your GitHub account
3. Click **Portfolio Items** in the left menu
4. Click the **New Portfolio Item** button
5. Fill in the details:
   - **Title**: The name of your piece
   - **Description**: A short description (shown in the grid)
   - **Image**: Upload a photo of your work
   - **Featured**: Check this box to highlight it
   - **Category**: Choose Furniture, Accessories, or Custom
   - **Details**: Write a longer description

6. Click **Publish** - the item automatically appears on your website!

All images are stored in your repository and served directly. Each language version can have different text while sharing the same images.
